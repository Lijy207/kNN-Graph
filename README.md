# $k$NN-Graph: An Adaptive Graph Model for $k$-Nearest Neighbors

This repository contains the official MATLAB implementation of the $k$NN-Graph framework.

## 1. System Requirements

### Software Dependencies & Operating Systems
- **Operating System:** Tested on Windows 10. (The code should be compatible with macOS and Linux systems that support MATLAB).
- **Software:** MATLAB R2024b (Tested). 

### Hardware Requirements
The software does not require any non-standard hardware to run. All development and testing were conducted on a standard desktop workstation with the following specifications:
- **CPU:** AMD Ryzen 9 3900X 12-Core (3.79 GHz)
- **RAM:** 32.0 GB
- **GPU:** NVIDIA GeForce GTX 1060 (6 GB)
- **Storage:** 4 TB Disk

## 2. Installation Guide

### Instructions
